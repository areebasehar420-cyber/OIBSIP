# Tribute Page: Marie Curie (Web Development Level 2, Task 2)

A responsive tribute page built with HTML5 and CSS3.

## Features
- Page title with the subject's name and a one-line tagline
- Prominent image (inline SVG illustration; can be replaced with a Wikimedia Commons photo)
- Biography section with four original paragraphs
- Timeline of key moments
- Distinctly styled quote block
- Multiple section background colours
- Two font styles: serif headings, sans-serif body
- Responsive layout for mobile and desktop

## Sources
Facts were researched on Wikipedia and Britannica and paraphrased.

## How to run
Open `index.html` in any browser.
