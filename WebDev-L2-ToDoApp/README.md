# To-Do Web App (Web Development Level 2, Task 3)

A task manager built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Add tasks with an input field and "Add Task" button
- Pending and Completed lists with live counts ("X pending", "Y completed")
- Mark complete toggle moves tasks between lists
- Inline edit and permanent delete
- Empty state messages for both lists
- Bonus: timestamps (added / completed)
- Bonus: tasks persist after refresh using `localStorage`

## How to run
Open `index.html` in any browser.
