# Calculator (Web Development Level 2, Task 1)

A browser-based calculator built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Display screen showing current input and the running operation
- Buttons 0-9 and a decimal point
- Operators: +, -, x, /
- Equals (=), Clear (C) and Backspace
- Division by zero shows an error message instead of crashing
- Operator chaining without a full reset (evaluated left to right, so 5 + 3 x 2 = 16)
- CSS Grid button layout
- All buttons use `addEventListener` (no inline `onclick`)
- No `eval()`: logic uses `switch`, `parseFloat()` and conditionals
- Bonus: keyboard support

## How to run
Open `index.html` in any browser.
